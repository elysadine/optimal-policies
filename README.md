# Optimal Teaching Policies via Spectral Radius Minimization

This repository contains the complete code and data for the paper:

**"Minimizing the spectral radius: a new principle for optimal teaching. Evidence from Madagascar"**

## Abstract

This paper introduces a statistical framework for modeling and optimizing student learning trajectories using absorbing controlled Markov processes. We prove that minimizing the spectral radius $\rho(Q)$ of the transient transition matrix maximizes the exponential convergence rate to mastery. Under a spectral monotonicity condition, the optimal policy is universally optimal it minimizes expected learning time for any initial student distribution.
